AVISO: protótipo experimental — não é alarme certificado

Este painel e o sensor MQ-6 não substituem detector certificado, inspeção profissional ou procedimentos de emergência. Uma leitura normal não garante que o ambiente esteja seguro. Se sentir cheiro de gás ou suspeitar de vazamento, aja mesmo que o painel não alerte.

O que fazer se houver suspeita de vazamento
  1. Afaste as pessoas e saia do local. Se for possível sem se expor, feche o registro do gás.
  2. Não acenda nem apague luzes, não ligue ou desligue aparelhos e não use telefone dentro do local.
  3. Já do lado de fora, em local seguro, ligue para os Bombeiros pelo 193 em caso de risco, vazamento forte, fogo ou mal-estar.

Não volte para dentro até que o local seja considerado seguro por profissionais.

Antes de usar o MQ-6

O valor do ADC sozinho não determina concentração nem risco. O fabricante do elemento MQ-6 recomenda mais de 24 horas de pré-aquecimento inicial e calibração do detector usando uma referência de GLP de 1000 ppm; a resistência e a resposta também variam com temperatura e umidade. Faça a calibração com procedimento e equipamento apropriados, nunca liberando gás em casa para testar.

Mesmo com calibração, este arranjo de hobby não deve ser usado como sistema de proteção à vida. Para proteção residencial, use detector apropriado e certificado, instalado conforme instruções do fabricante, e procure profissional qualificado.

Verificador do divisor de tensão

Confira o circuito antes de ligar a saída analógica ao ESP32. Use valores reais dos resistores e tensão medida.

Vout calculada: —

Informe os valores.

Cálculo ideal: Vout = Vin × R2 / (R1 + R2). Este cálculo não considera tolerância, transientes nem limites específicos da sua placa. Confirme o datasheet do ESP32 e meça o circuito; não trate o cálculo como garantia de proteção.

Checklist para leituras úteis

  • Confirme o modelo exato do ESP32 e do módulo MQ-6, a alimentação e o divisor usados.
  • Faça o aquecimento inicial indicado na folha técnica e estabilize o conjunto antes de registrar a linha de base.
  • Registre leituras em ar limpo e condições ambientais conhecidas; valide a resposta em ambiente de teste controlado e com referência adequada.
  • Configure o limiar apenas para seu protótipo validado. Não copie um valor ADC de outro módulo ou projeto.
  • Use um detector certificado independente para qualquer necessidade de segurança.

Formato serial compatível

Uma amostra por linha, usando vírgulas como separador. O primeiro campo é a leitura ADC bruta.

#include <DHT.h>

const int mq6Pin = 34; // saída analógica do módulo, após circuito compatível
const int dhtPin = 4;
#define DHTTYPE DHT11
DHT dht(dhtPin, DHTTYPE);

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
  dht.begin();
}

void loop() {
  int adc = analogRead(mq6Pin);
  float tempC = dht.readTemperature();
  float umidade = dht.readHumidity();
  Serial.print(adc);
  Serial.print(',');
  if (isnan(tempC)) Serial.print("nan"); else Serial.print(tempC, 1);
  Serial.print(',');
  if (isnan(umidade)) Serial.println("nan"); else Serial.println(umidade, 0);
  delay(500);
}

Este exemplo apenas transmite dados e não implementa alarme certificado, calibração, redundância ou controle seguro. Verifique compatibilidade elétrica antes de conectar. Nunca acione válvulas ou cargas de segurança com base somente neste exemplo.
